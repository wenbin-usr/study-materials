## 转换方式

- **文本提取**:PyMuPDF 按行读取文本(保留字体信息),非 OCR;原 PDF 均为文本型,文字无损。
- **层级恢复**:按字号推断标题层级(章 = `#`,节 = `##`,小节 = `###`,小标题 = `####`);原加粗正文保留为 `**…**`,行内代码保留为 `` `…` ``。
- **代码块**:按等宽字体(LucidaConsole)识别,保留缩进与中文注释,并自动标注 `python` / `bash`;代码块左侧的原行号列已剔除。
- **表格**:识别出的表格转为 Markdown 表格(共 27 处)。
- **图片**:按原始位置插入引用,图片文件抽取到 `assets/<文件名>/img-NNN.<ext>`,与 md 使用相对路径关联。
- **排版清洗**:剔除页眉页脚/行号;软换行按中文规则合并为段落;有序/无序列表还原为 Markdown 列表。

## 已知限制

- 段落合并基于"行宽 + 缩进"启发式,个别地方可能多并/少并一句话;
- 表格单元格内的换行以空格连接;合并单元格按首格内容输出;
- 原 PDF 的颜色、字号、页眉页脚等版式信息不保留;
- 文中少量示意图若原 PDF 以矢量绘图(而非嵌入位图)绘制,可能不会被导出为图片。

## 使用建议

用 Obsidian、Typora 或 VS Code(安装 Markdown/Mermaid 插件)打开即可获得最佳阅读体验;请保持 `assets/` 目录与 md 文件的相对位置不变,图片才能正常显示。
